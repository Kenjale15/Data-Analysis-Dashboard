# Supermarket Sales Dashboard (Interactive Dashboard creation using MS Excel )
## Project Objective
The objective of this project is to design an interactive Sales Dashboard using Microsoft Excel to visualize key metrics such as total sales, sales by product, region, and representative, enabling quick decision-making through clear data insights.

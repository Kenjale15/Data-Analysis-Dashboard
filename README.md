# Supermarket Sales Dashboard (Interactive Dashboard creation using MS Excel )
## Project Objective
The objective of this project is to design an interactive Sales Dashboard using Microsoft Excel to visualize key metrics such as total sales, sales by product, region, and representative, enabling quick decision-making through clear data insights.

## Dataset used

You can find the dataset used in this project [here]  
- <a href ="https://github.com/Kenjale15/Data-Analysis-Dashboard/blob/main/Sample_Sales_Data.xlsx">Dataset </a>

## What I Learned
- This dashboard was created as my first hands-on project to learn data visualization using Excel. It helped me understand PivotTables, slicers, chart types, and layout formatting.
- Dashboard Interaction <a href="https://github.com/Kenjale15/Data-Analysis-Dashboard/blob/main/Sales%20dashboard%20screenshot.png"> View Dashboard </a>

This Excel dashboard analyzes supermarket sales data using:
- Pivot Tables
- Interactive Slicers
- KPI Cards and Charts
- Region-wise and Product-wise insights

Tools Used:
- Microsoft Excel
- Pivot Charts
- Slicer
- Dashboard Design
